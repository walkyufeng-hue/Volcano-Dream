# 火山梦绘AI｜产品定位一页纸

> 文档版本：V1.0  
> 更新日期：2026-07-13  
> 产品负责人：火山  
> 当前阶段：MVP 完成，小范围公开测试前

## 1. 一句话定位

火山梦绘AI是一款面向对梦境好奇、希望梳理近期情绪的中文用户的 AI 梦境解读产品，通过结构化文字解读与个性化梦幻配图，提供低门槛、温和且可保存的自我反思体验。

## 2. 用户问题

用户醒来后对梦境有记忆、有情绪，却经常遇到以下问题：

- 传统解梦网站以固定词条为主，无法理解完整情境与个人感受。
- 通用聊天机器人可以回答，但缺少稳定的解读结构、产品体验和结果沉淀。
- 用户不一定需要专业心理咨询，只希望获得一次轻量、温和、有启发的梳理。
- 纯文字结果缺少情绪价值和分享、保存动力。
- 梦境涉及隐私，用户会担心内容是否公开或长期保存。

## 3. 目标用户假设

### 核心用户

- 18～35 岁中文互联网用户。
- 对梦境、心理、自我探索或情绪记录感兴趣。
- 偶尔做印象深刻的梦，但没有持续写梦境日记的习惯。
- 愿意尝试 AI 内容产品，希望结果快速、好读、具有个性化。

### 次要用户

- 有梦境记录习惯，希望获得辅助整理的人。
- 喜欢梦幻插画，希望保存或分享梦境画面的人。
- 因近期工作、关系或生活变化而关注梦境的人。

### 暂不服务

- 寻求医学诊断、心理治疗或危机干预的用户。
- 希望获得确定预言、博彩建议或重大人生决策结论的用户。
- 需要专业梦境研究工具、多人协作或大规模数据分析的机构用户。

> 说明：以上用户画像是当前产品假设，需要通过真实访谈和行为数据验证。

## 4. 核心使用场景

1. **醒来后快速记录**：用户记得一个清晰片段，希望立即了解可能的象征与情绪线索。
2. **反复出现的梦**：用户多次梦见类似人物或场景，希望获得更结构化的梳理。
3. **近期压力与变化**：用户在工作、关系或生活变化期间，希望通过梦境进行轻量自我反思。
4. **保存梦境画面**：用户喜欢生成的插画，希望下载、收藏或分享。
5. **回看个人记录**：用户希望重新查看最近的梦境解读与配图。

## 5. 价值主张

### 功能价值

- 理解完整梦境，而不是只匹配单个关键词。
- 固定输出梦境意象、心理映射、生活启示和行动建议。
- 文字完成后自动生成 16:9 梦幻插画。
- 支持历史记录、复制解读、下载图片和意见反馈。

### 情绪价值

- 用温和、不恐吓、不绝对化的方式回应用户。
- 帮助用户把模糊感受转化为可以理解和表达的内容。
- 将一次短暂梦境转化为可以保存的文字与画面。

### 信任价值

- 明确说明结果仅供娱乐和自我反思。
- 不把梦境解释为确定预言。
- API Key 只保存在后端。
- 当前历史记录保存在用户本地浏览器，不公开展示。

## 6. 差异化定位

| 对比对象 | 常见特点 | 火山梦绘AI的差异 |
|---|---|---|
| 传统周公解梦网站 | 固定词条、广告多、缺少上下文 | 理解完整描述，结合传统梦文化与现代心理学视角 |
| 通用 AI 聊天机器人 | 能回答但体验不固定 | 固定解梦结构、自动配图、历史记录和费用保护 |
| 梦境日记工具 | 强调记录，解读能力较弱 | 自动生成文字解读与视觉化梦境画面 |
| 心理咨询服务 | 专业但成本高、门槛高 | 轻量、即时，但明确不替代专业服务 |

## 7. 产品原则

1. **不制造恐惧**：不输出灾难预言、宿命判断或危言耸听内容。
2. **不假装诊断**：不把梦境当作医学或心理诊断依据。
3. **先给用户价值，再追求内容长度**：相关、清晰比冗长更重要。
4. **默认控制成本**：限流、全站预算和停止生成功能必须长期保留。
5. **保护梦境隐私**：不在分析和埋点中记录完整梦境原文。
6. **文字与画面一致**：图片必须来源于本次梦境与解读，不做无关装饰。

## 8. 当前 MVP 范围

### 已完成

- 最多 500 字梦境输入与示例梦境。
- DeepSeek 流式文字解读，关闭思考模式。
- 文字完成后自动生成 1K、16:9 梦幻配图。
- 图片模型失败时的回退能力。
- 每个 IP 滚动 24 小时最多 3 次。
- 全站文字、图片每日总次数保护。
- 剩余次数显示、停止生成和防重复提交。
- 复制解读、下载图片。
- 当前浏览器最近 10 条历史记录与配图。
- 意见反馈与本地 SQLite 保存。
- 响应式网页和结果弹窗。

### 暂不包含

- 登录注册、订阅、支付。
- 云端历史记录和跨设备同步。
- 梦境社区和公开发布。
- 多轮追问和人工专家服务。
- 多模型自由切换。

## 9. 北极星指标与核心漏斗

### 建议北极星指标

**每周获得有效价值的解梦次数**：文字解读成功后，用户完成复制、下载图片、打开历史记录或再次使用中的至少一个行为。

选择原因：单纯“生成次数”只能代表调用 API；后续价值行为更能说明结果是否真正有用。

### 核心漏斗

访问首页 → 输入梦境 → 点击解读 → 文字生成成功 → 图片生成成功 → 复制/下载/回看 → 7 天内再次使用

### MVP 建议观察指标

- 输入到提交转化率。
- 文字生成成功率与平均首字时间。
- 图片生成成功率与平均耗时。
- 停止生成率。
- 复制解读率、图片下载率、历史记录打开率。
- 次日留存、7 日留存。
- 单次文字与图片成本。
- 每百次生成的有效反馈数量。

> 当前尚未接入完整匿名埋点，以上指标为下一阶段建设内容。

## 10. 商业化假设

### 免费层

- 每个 IP 滚动 24 小时 3 次。
- 基础文字解读与普通清晰度图片。
- 当前浏览器最近 10 条历史记录。

### 待验证付费权益

- 更多解梦次数。
- 云端历史与跨设备同步。
- 高清图片、额外重新生图次数。
- 更长时间的梦境档案与主题回顾。

### 验证顺序

先验证持续使用和付费意愿，再开发登录、订阅和支付，不以功能完成代替商业验证。

## 11. 当前关键风险

- 结果质量不稳定，缺少标准化模型评测和 Prompt 版本对比。
- 自动生图可能成为主要成本来源。
- IP 限流受生产代理配置影响，必须使用 Redis 或 Upstash。
- 历史记录仅在当前浏览器，用户清理数据或换设备后会丢失。
- 反馈 SQLite 在无持久化磁盘的部署平台上可能丢失。
- 梦境属于敏感个人内容，需要在输入区域进一步强化第三方 AI 与隐私提醒。

## 12. 下一阶段目标

1. 建立 40～50 条匿名梦境评测集和模型评分体系。
2. 接入不采集梦境原文的匿名事件统计。
3. 完成 10～20 位目标用户访谈。
4. 根据生成成功率、留存和反馈完成一次版本复盘。
5. 使用意愿按钮验证云端历史、高清图片和更多次数的付费需求。
