# 火山梦绘AI｜项目梳理（简历版）

- **项目背景：** 针对传统解梦网站依赖固定词条、缺少上下文理解，以及通用 AI 对话产品缺少垂直体验、结果沉淀和费用控制的问题，从 0 到 1 主导搭建 AI 梦境解读产品，验证“结构化文字解读 + 个性化梦境配图”的用户价值。

- **产品定位：** 面向对梦境、心理和自我探索感兴趣的中文用户，提供梦境输入、AI 流式解读、16:9 梦幻配图和本地历史记录的一站式 Web 产品，帮助用户以低门槛、非诊断的方式梳理梦境意象与近期情绪。

- **职责描述：**

  - **0-1 产品规划与 MVP 落地：** 主导目标用户、核心场景、产品边界和版本范围梳理，输出产品定位、完整 PRD、用户流程、业务规则及验收清单；聚焦梦境解读单一核心场景，明确暂缓登录、订阅和社区等非核心功能。

  - **AI 产品方案设计：** 基于 OpenRouter 接入 DeepSeek 文字模型，设计“梦境意象—心理映射—生活启示—行动建议”的结构化 Prompt，并通过 SSE 实现流式输出；关闭思考模式，在生成质量、响应速度和调用成本之间进行平衡。

  - **多模态生成链路：** 设计文字完成后自动生图的产品流程，接入 1K、16:9 梦幻插画模型，并配置地区限制回退方案；统一加载、成功、失败、重试、停止生成等状态，保证图片失败不影响文字结果阅读。

  - **用户体验与交互优化：** 基于 Figma 完成桌面端与移动端页面重构，持续优化首屏输入效率、结果弹窗、滚动控制和历史回看体验；落地示例梦境、剩余次数、复制解读、下载图片、意见反馈和最近 10 条本地历史记录等功能。

  - **费用与安全机制：** 设计每个 IP 滚动 24 小时最多 3 次的免费额度，并增加全站滚动 24 小时最多 60 次文字、20 次图片的费用总闸门；通过一次性图片凭证、防重复提交、停止生成、API Key 后端隔离和可信代理校验降低滥用及成本风险。

  - **质量评测与产品规范：** 建立覆盖相关性、个性化、结构完整性、安全性、响应速度和成本的 AI 评测框架，规划 40 条梦境测试集、文字与图片上线阈值、Prompt 版本记录和失败案例库，为后续模型切换和效果迭代提供统一标准。

  - **商业化路径规划：** 采用“免费限次验证需求—评估留存与付费意愿—再建设登录订阅”的分阶段策略，规划更多次数、云端历史、高清图片和重新生图等候选付费权益，避免在用户价值验证前投入复杂商业系统。

- **取得成果：**

  - 从 0 到 1 完成可运行的 AI 梦境解读 MVP，打通“用户输入—流式文字解读—自动梦境配图—结果操作—历史沉淀—用户反馈”的完整产品链路。

  - 建立用户级限流与全站预算双层费用保护，将匿名用户额度明确控制为 **3 次/滚动 24 小时**，并支持通过环境变量独立关闭文字或图片能力，降低公开上线后的 API 费用失控风险。

  - 完成主图片模型、地区限制回退模型和一次性图片凭证机制，支持图片自动生成、失败重试、历史图片保存与下载，提升多模态链路的可用性和容错能力。

  - 沉淀产品定位、PRD 和 AI 模型评测三类标准文档；完成前端生产构建、代码规范检查及 **7 项后端安全回归测试**，为后续公开测试、数据埋点和商业化验证建立可迭代基础。

## 面试展开重点

1. 为什么聚焦梦境解读，而不是继续保留塔罗等多个占卜入口。
2. 为什么先采用匿名限次，不立即开发登录、订阅和支付。
3. 为什么文字完成后自动生图，以及如何处理自动生图带来的成本问题。
4. 如何通过固定测试集、硬性安全阈值、延迟和成本共同决定模型选型。
5. 如何在产品体验、模型质量、隐私安全和 API 费用之间做取舍。
